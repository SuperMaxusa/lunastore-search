LunaStore OpenSearch


Note: this version doesn't support search suggestions. You can deploy your local server for that, see the guide on GitHub
  • What is this? This is an OpenSearch Description Document to search on LunaStore, adds as a new search provider.
  • How to use? Click the big "Install!" button above and if you use:
    • Internet Expolrer 7+, Firefox 2+: Confirm the installation (note: suggestions doesn't work on Internet Explorer 7)
    • Firefox 2+ (fallback): Open the drop-down menu in the search bar (on this page) and select 'Add "LunaStore"'
    • Firefox 61+: Click on the three dots on the search bar (on this page) and select 'Add "LunaStore" in one-click search'
    • Firefox 89+: Right-click on the search bar (on this page) and select 'Add "LunaStore"'
    • Modern Chromium: Not available (i guess?), sorry :(
